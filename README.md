# My AI Project - Sentiment Analyzer

An Agentic AI project built with Hugging Face Transformers that analyzes text sentiment (Positive/Negative/Neutral) in real-time using NLP.

## 🚀 Features
- Real-time sentiment analysis
- Built with Transformers & PyTorch
- Gradio-based user interface
- Supports English text

## 🛠️ Tech Stack
- Python
- Hugging Face Transformers
- Gradio
- GitHub & Colab

## 🔗 How to Run
1. Open `Untitled0.ipynb` in Google Colab
2. Install dependencies: `pip install transformers torch gradio`
3. Run the app
